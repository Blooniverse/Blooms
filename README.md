# Blooms CMS

Blooms was a lean and semantic CMS developed manually in 2018.

# Features
- HTML aggregation (no markdown or the like)
- Zero admin
- Zero login
- Direct integration in Linux file explorers, macOS Finder, Windows Explorer
- Onchain focussed

# Core tech
- PHP
- Javascript
- HTML
- CSS
- XML
- XSL
- RDFa
